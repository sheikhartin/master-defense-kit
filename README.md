# بستار دفاع ارشد BCOA

ابزار تمرین گام‌به‌گام، آرام و کاملاً آفلاین برای جلسه دفاع پایان‌نامه کارشناسی ارشد با موضوع
«الگوریتم بهینه‌سازی سسک سرسیاه (BCOA): یک الگوریتم فراابتکاری جدید برای مسائل بهینه‌سازی سراسری و مهندسی».

همه محتواهای ارائه بر پایه **سناریوی نهایی** ساخته شده است: فهرست هشت‌بخشی، چیدمان فشرده نوزده
اسلایدی و چیدمان گسترده بیست‌اسلایدی (با اسلاید اختیاری «وراثت جهت و رقابت سرزمینی» به‌عنوان شماره ۱۱)،
زمان‌بندی دقیق، متن گفتار، فرمول‌ها، پرسش‌های داور و چک‌لیست روز دفاع.

## ویژگی‌ها

- **نقشه راه دفاع**: نمای کامل هشت بخش، زمان‌بندی گفتار چیدمان فشرده (۱۸:۳۰) و گسترده (۱۹:۱۵)، یک دقیقه حاشیه امن و هدف پایان ۱۸:۴۵ تا ۱۹:۰۰
- **جلسه تمرینی**: شبیه‌سازی زمان‌دار با تایمر اسلاید و تایمر کل که هم‌زمان و با یک کلید توقف می‌کنند
- **هشدار نرم**: نمایش بصری پایان زمان و صدای ملایم اختیاری در ۱۰، ۵ و صفر ثانیه مانده
- **شروع از هر اسلاید** و **ادامه دقیق از آخرین جایگاه** پس از بستن و بازکردن برنامه
- **فرمول‌های کامل و پیش‌رندر**: همه روابط با کیتکس به‌صورت محلی رندر و کش می‌شوند؛ برگه تقلب بدون تأخیر باز می‌شود
- **مفاهیم پرکاربرد روز دفاع** (p-value، انحراف معیار، فریدمن، ویلکاکسون و نگاشت متغیرهای گسسته) و **جدول‌های پشتیبان**: قابلیت اطمینان، تحلیل حذف مؤلفه‌ها و اندازه اثر
- **دانلود PDF تمیز**: خروجی چاپی A4 برای هر بخش (نقشه راه، متن کامل ارائه، برگه تقلب، بانک پرسش، چک‌لیست) و همچنین کل وب‌سایت در یک سند؛ از منوی دانلود در سربرگ یا با Alt + P (بخش فعلی) و Alt + Shift + P (کل وب‌سایت)
- **یادداشت شخصی و هایلایت نرم** زیر اسلایدها، فرمول‌ها و پرسش‌ها
- **کنترل تایپوگرافی سراسری**: اندازه متن و فاصله خطوط برای خواندن طولانی
- **حالت تمرکز**: پنهان‌کردن ناوبری و عناصر فرعی؛ فقط محتوا و تایمر می‌ماند
- **پشتیبانی کامل صفحه‌کلید** برای جابه‌جایی میان اسلایدها و کنترل تایمر
- **بانک پرسش داور** با پاسخ پیشنهادی، فیلتر دسته و شبیه‌ساز پرسش تصادفی
- **چک‌لیست‌های تعاملی** روز دفاع با ذخیره خودکار

## حریم خصوصی و آفلاین بودن

- برنامه هیچ درخواست شبکه‌ای انجام نمی‌دهد؛ هیچ CDN، فونت آنلاین، API یا سرویس خارجی استفاده نمی‌شود
- قلم فارسی «وزیرمتن» و قلم‌های کیتکس از بسته‌های محلی نصب‌شده بارگذاری می‌شوند
- همه یادداشت‌ها، هایلایت‌ها، تنظیمات و پیشرفت تمرین فقط در `localStorage` همان دستگاه ذخیره می‌شوند
- خروجی تولیدی (build) به‌کمک سرویس‌کارگر (Service Worker) قابل نصب و استفاده کاملاً آفلاین است

## اجرا و ساخت

پیش‌نیاز: Node.js نسخه ۲۰ یا بالاتر.

```bash
npm install        # نصب وابستگی‌های محلی (فقط یک بار)
npm run dev        # اجرای حالت توسعه روی پورت ۳۰۰۰
npm run build      # ساخت نسخه تولیدی در پوشه dist
npm run preview    # پیش‌نمایش نسخه تولیدی
npm run lint       # بررسی تایپ (TypeScript)
npm run verify     # آزمون‌های یکپارچگی داده و قواعد نگارش
npm run icons      # بازسازی همه آیکون‌ها از نشان واحد برند (آفلاین)
```

## نشان برند و آیکون‌ها (زبان طراحی یکپارچه)

همه آیکون‌ها (فاوآیکون SVG و ICO، آیکون iOS، آیکون‌های نصب PWA و نسخه maskable و حتی نشان
داخل سربرگ و پابرگ) از یک منبع حقیقت واحد در `src/lib/brand.mjs` ساخته می‌شوند. مفهوم نشان
«سپر زمان» است: سپر نماد دفاع و عقربه‌های درون آن نماد تمرین زمان‌دار. اسکریپت
`scripts/build-brand.mjs` بدون هیچ وابستگی بیرونی، نسخه‌های برداری و پیکسلی را در اندازه‌های
واقعی رستر می‌زند تا در ۱۶ پیکسل هم خوانا بماند. برای بازسازی پس از تغییر نشان، `npm run icons`
را بزنید.

## راهنمای صفحه‌کلید

همه میان‌برها با `e.code` تطبیق داده می‌شوند تا روی کیبورد فارسی و انگلیسی یکسان عمل کنند،
و وقتی یک پنجره باز است یا کاربر در حال تایپ است به‌صورت خودکار سکوت می‌کنند. راهنمای کامل و
زمینه‌ای با کلید `H` یا `?` باز می‌شود.

**در همه بخش‌ها:**

- **راهنمای کلیدها**: H یا ?
- **حالت تمرکز**: F
- **هشدار صوتی**: M
- **بستن لایه / خروج از تمرکز**: Esc
- **پرش به پنج بخش**: Alt + ۱ تا ۵
- **نسخه چاپی برگه تقلب**: Alt + P

**در جلسه تمرینی:**

- **اسلاید بعد**: کلید چپ یا PageDown
- **اسلاید قبلی**: کلید راست یا PageUp
- **شروع و توقف هم‌زمان تایمرها**: Space یا P
- **تایمر اسلاید از نو**: R
- **کل جلسه از نو**: Shift+R
- **پرش به اسلاید ۱ تا ۱۰**: اعداد ۱ تا ۹ و ۰
- **پرش به اسلایدهای ۱۱ به بعد**: Shift + عدد
- **اولین / آخرین اسلاید**: Home و End
- **چیدمان گسترده با اسلاید اختیاری**: O

**در پرسش‌های داور:** پرسش بعدی `N`، نمایش پاسخ `Enter`، چینش تازه `R`.

میان‌برهای تک‌کلیدی (مشمول دسترس‌پذیری WCAG 2.1.4) را می‌توان از «تنظیمات خواندن» یا از خود
راهنما خاموش کرد؛ ترکیب‌های Alt و کلیدهای جهت‌دار همیشه فعال می‌مانند.

## ساختار پروژه

```
index.html
vite.config.ts
public/            آیکون‌های برنامه (همه محلی، ساخته‌شده از نشان واحد)
src/
  main.tsx         نقطه ورود و بارگذاری قلم‌ها
  App.tsx          پوسته، ناوبری، حالت تمرکز، پابرگ و چاپ
  index.css        سیستم طراحی، چاپ، قواعد RTL و هاور بدون لرزش
  types.ts         انواع داده
  data/            محتوای سناریوی نهایی (اسلایدها، پرسش‌ها، فرمول‌ها، چک‌لیست‌ها)
  lib/             ابزار فارسی، کش فرمول‌ها، ذخیره محلی، زمان‌بندی
    brand.mjs      هندسه و پالت نشان برند (منبع حقیقت همه آیکون‌ها)
    keys.ts        قواعد خالص تطبیق کلیدها (مستقل از چیدمان زبان)
    use-global-shortcuts.ts  میان‌برهای سراسری همه تب‌ها
    ui-bus.ts      شمارنده لایه‌های باز برای سکوت میان‌برها
    use-modal.ts   رفتار یکپارچه پنجره‌ها (فوکوس، Escape، Tab)
  labs/            پنج صفحه اصلی برنامه
  components/      اجزای مشترک، نشان برند (BrandMark) و نسخه چاپی
scripts/build-brand.mjs  ساخت آیکون‌ها از نشان واحد (کاملاً آفلاین)
tests/verify-all.cjs  آزمون‌های مستقل داده‌ها و قواعد
```

## قواعد نگارشی که در این پروژه رعایت شده است

- هیچ رقم یا حرف فارسی داخل عبارت‌های LaTeX نوشته نمی‌شود (همه فرمول‌ها فقط نویسه ASCII دارند)
- زمان‌ها با ارقام فارسی و واژه «تا» نوشته می‌شوند و هیچ em dash یا en dash در محتوا به‌کار نمی‌رود
- هر عبارت انگلیسی با معادل فارسی دقیق همراه است و نام انگلیسی همیشه در جای درست خودش (کنار عنوان) نمایش داده می‌شود
- ظرف‌های فرمول چپ‌به‌راست و ایزوله هستند؛ اسکرول افقی فقط در صورت نیاز داخل همان ظرف رخ می‌دهد و هرگز در کل صفحه
