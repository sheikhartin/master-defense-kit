# بستار دفاع ارشد BCOA

ابزار تمرین گام‌به‌گام، آرام و کاملاً آفلاین برای جلسه دفاع پایان‌نامه کارشناسی ارشد با موضوع
«الگوریتم بهینه‌سازی سسک سرسیاه (BCOA): یک الگوریتم فراابتکاری جدید برای مسائل بهینه‌سازی سراسری و مهندسی».

همه محتواهای ارائه از پوشه **`content/`** خوانده می‌شوند (فایل‌های Markdown و YAML جداگانه برای هر اسلاید، پرسش‌ها، برگه تقلب و چک‌لیست). هیچ متن دفاعی داخل کد React قفل نشده است. مدت هر اسلاید در فایل همان اسلاید با `durationSec` و برچسب انگلیسی `estimatedTime` مشخص می‌شود و مجموع آن‌ها مدت کل گفتار را می‌سازد.

بسته پیش‌فرض BCOA: **۲۰ اسلاید**، گفتار **۱۹:۱۵** (۱۱۵۵ ثانیه) + حاشیه امن **۱:۰۰**؛ هدف پایان **۱۹:۳۰ تا ۱۹:۴۵**.

## ویژگی‌ها

- **نقشه راه دفاع**: نمای کامل هشت بخش، زمان‌بندی گفتار ۲۰ اسلایدی (۱۹:۱۵)، یک دقیقه حاشیه امن و هدف پایان ۱۹:۳۰ تا ۱۹:۴۵
- **جلسه تمرینی**: شبیه‌سازی زمان‌دار با تایمر اسلاید و تایمر کل که هم‌زمان و با یک کلید توقف می‌کنند
- **همه اسلایدها در مسیر اصلی**: هیچ اسلایدی «اختیاری» یا پنهان نیست
- **هشدار نرم**: نمایش بصری پایان زمان و صدای ملایم در ۱۰، ۵ و صفر ثانیه مانده (با دکمه «آزمایش صدا» در تنظیمات)
- **پالت‌های حرفه‌ای**: سبز، آبی، نارنجی، بنفش و قرمز؛ نشان برند با رنگ تأکید پالت هماهنگ می‌شود
- **شروع از هر اسلاید** و **ادامه دقیق از آخرین جایگاه** پس از بستن و بازکردن برنامه
- **فرمول‌های کامل و پیش‌رندر**: همه روابط با کیتکس به‌صورت محلی رندر و کش می‌شوند
- **مفاهیم پرکاربرد روز دفاع** و **جدول‌های پشتیبان**: قابلیت اطمینان، تحلیل حذف مؤلفه‌ها و اندازه اثر
- **دانلود PDF تمیز**: خروجی چاپی A4 برای هر بخش و کل وب‌سایت (Alt + P / Alt + Shift + P)
- **یادداشت شخصی، یادداشت‌های کلیدی ستاره‌پذیر، و هایلایت بلوکی پاراگراف** (پدینگ و گوشه گرد ملایم)
- **علامت مهم روی یادداشت‌های مربی** (نکات اجرایی هر اسلاید)
- **کنترل تایپوگرافی سراسری**: اندازه متن و فاصله خطوط
- **حالت تمرکز**: پنهان‌کردن ناوبری و عناصر فرعی
- **پشتیبانی کامل صفحه‌کلید** برای جابه‌جایی میان اسلایدها و کنترل تایمر
- **بانک پرسش داور** با پاسخ پیشنهادی، فیلتر دسته و شبیه‌ساز پرسش تصادفی
- **چک‌لیست‌های تعاملی** روز دفاع با ذخیره خودکار
- **محتوای بیرونی و گسترش‌پذیر**: ویرایش `content/` بدون دست‌زدن به منطق برنامه

## راهنمای جامع استفاده

### نصب و اجرا

پیش‌نیاز: Node.js نسخه ۲۰ یا بالاتر.

```bash
npm install        # نصب وابستگی‌های محلی (فقط یک بار)
npm run content    # کامپایل content/ به src/content.generated.ts
npm run dev        # اجرای حالت توسعه روی پورت ۳۰۰۰ (ابتدا content را می‌سازد)
npm run build      # ساخت نسخه تولیدی در پوشه dist
npm run preview    # پیش‌نمایش نسخه تولیدی
npm run lint       # بررسی تایپ (TypeScript)
npm run verify     # آزمون‌های یکپارچگی داده، محتوا و قواعد نگارش
npm run icons      # بازسازی همه آیکون‌ها از نشان واحد برند (آفلاین)
```

پس از `npm run build`، پوشه `dist/` یک PWA کامل است و با Service Worker به‌صورت آفلاین کار می‌کند.

### پنج بخش برنامه

| بخش | کاربرد |
|-----|--------|
| نقشه راه دفاع | ساختار هشت‌بخشی، پنجره‌های زمانی، اصل حاکم |
| جلسه تمرینی | تایمر دوگانه، متن گفتار، فرمول، یادداشت، صدا |
| برگه تقلب | روابط کامل، مفاهیم آماری، ارقام و جدول‌ها |
| پرسش‌های داور | بانک پرسش + فیلتر + شبیه‌ساز تصادفی |
| چک‌لیست روز دفاع | آمادگی فایل/سالن/ارائه + جدول نگو/بگو |

### جلسه تمرینی (گام‌به‌گام)

1. از نقشه راه «شروع تمرین کامل» را بزنید یا مستقیم به تب جلسه تمرینی بروید.  
2. در صورت نیاز، از تنظیمات (آیکون چرخ‌دنده) **هشدار صوتی** را روشن کنید و با **آزمایش صدا** از کارکرد بلندگو مطمئن شوید.  
3. «شروع / ادامه» یا کلید Space / P را بزنید؛ هر دو تایمر با هم جلو می‌روند.  
4. نزدیک پایان اسلاید، وضعیت به «کمی سرعت بگیر» و سپس «زمان اسلاید تمام شد» می‌رود؛ اگر صدا روشن باشد در ۱۰، ۵ و ۰ ثانیه بوق ملایم می‌شنوید.  
5. پاراگراف‌های گفتار، نکات اجرایی مربی و یادداشت‌های کلیدی شخصی را می‌توانید با ستاره **مهم** کنید؛ هایلایت به‌صورت بلوک با پدینگ و گوشه گرد دیده می‌شود.  
6. جایگاه جلسه هر چند ثانیه در همین دستگاه ذخیره می‌شود؛ بعداً از نقشه راه «ادامه تمرین» در دسترس است.

### پالت رنگ

از تنظیمات خواندن، یکی از پنج پالت را انتخاب کنید:

- سبز کاج (پیش‌فرض)
- آبی دریایی
- نارنجی خاکی
- بنفش آرام
- قرمز آجری

رنگ دکمه‌های اصلی، ناوبری فعال، نوار پیشرفت و **پس‌زمینه نشان برند** با پالت عوض می‌شود. رنگ طلایی «مهم» و قرمز خاکی «هشدار زمان» در همه پالت‌ها ثابت می‌مانند تا معنایشان عوض نشود. انتخاب شما در `localStorage` می‌ماند. فاوآیکون تب مرورگر هم‌رنگ پالت می‌شود؛ آیکون نصب PWA روی صفحه اصلی دستگاه معمولاً تا نصب مجدد سبز پیش‌فرض می‌ماند (محدودیت سیستم‌عامل).

### ویرایش محتوا (برای هر دفاع، نه فقط BCOA)

منبع حقیقت: پوشه `content/`. راهنمای کامل فیلدها: [`content/README.md`](content/README.md).

| مسیر | محتوا |
|------|--------|
| `content/deck/*.md` | یک فایل برای هر اسلاید؛ `durationSec` + `estimatedTime` انگلیسی |
| `content/cheat/` | فرمول‌ها، مفاهیم، ارقام، جدول‌ها |
| `content/qa/` | پرسش‌های اصلی، سخت، تمرین و دسته‌ها |
| `content/checklist/` | چک‌لیست‌ها و نگو/بگو |
| `content/roadmap/` | اصل حاکم، مرز ادعا، روش تمرین |
| `content/meta.yaml` | عنوان کیت، حاشیه امن، آفست هدف پایان |

پس از ویرایش:

```bash
npm run content   # یا npm run dev
```

جمع `durationSec` همه اسلایدها = مدت کل گفتار. مثال بسته فعلی:

| اسلاید | مدت (ثانیه) | estimatedTime |
|--------|-------------|---------------|
| ۱ عنوان | ۳۵ | 35 seconds |
| ۲ فهرست | ۲۰ | 20 seconds |
| … | … | … |
| **جمع ۲۰ اسلاید** | **۱۱۵۵** | **19:15** |

### خروجی PDF

از منوی دانلود در سربرگ، یا:

- `Alt + P` بخش فعلی  
- `Alt + Shift + P` کل وب‌سایت  

در گفت‌وگوی چاپ مرورگر، «ذخیره به‌صورت PDF» را انتخاب کنید. رنگ تأکید چاپ از پالت فعال پیروی می‌کند.

### حریم خصوصی و آفلاین بودن

- برنامه هیچ درخواست شبکه‌ای انجام نمی‌دهد؛ هیچ CDN، فونت آنلاین، API یا سرویس خارجی استفاده نمی‌شود  
- قلم فارسی «وزیرمتن» و قلم‌های کیتکس از بسته‌های محلی نصب‌شده بارگذاری می‌شوند  
- همه یادداشت‌ها، هایلایت‌ها، تنظیمات و پیشرفت تمرین فقط در `localStorage` همان دستگاه ذخیره می‌شوند (پیشوند `bcoa-defense:`)  
- خروجی تولیدی به‌کمک Service Worker قابل نصب و استفاده کاملاً آفلاین است  

## نشان برند و آیکون‌ها

همه آیکون‌ها (فاوآیکون، iOS، PWA و نشان سربرگ) از `src/lib/brand.mjs` ساخته می‌شوند. مفهوم نشان «سپر زمان» است. رنگ کاشی نشان **داخل برنامه** از پالت فعال می‌آید؛ آیکون‌های نصب PWA نسخه پیش‌فرض سبز را نگه می‌دارند مگر با `npm run icons` بازسازی شوند.

## راهنمای صفحه‌کلید

همه میان‌برها با `e.code` تطبیق داده می‌شوند تا روی کیبورد فارسی و انگلیسی یکسان عمل کنند، و وقتی یک پنجره باز است یا کاربر در حال تایپ است به‌صورت خودکار سکوت می‌کنند. راهنمای کامل با کلید `H` یا `?` باز می‌شود.

**در همه بخش‌ها:**

- **راهنمای کلیدها**: H یا ?  
- **حالت تمرکز**: F  
- **هشدار صوتی**: M  
- **بستن لایه / خروج از تمرکز**: Esc  
- **پرش به پنج بخش**: Alt + ۱ تا ۵  
- **PDF بخش فعلی**: Alt + P  
- **PDF کل وب‌سایت**: Alt + Shift + P  

**در جلسه تمرینی:**

- **اسلاید بعد**: کلید چپ یا PageDown  
- **اسلاید قبلی**: کلید راست یا PageUp  
- **شروع و توقف هم‌زمان تایمرها**: Space یا P  
- **تایمر اسلاید از نو**: R  
- **کل جلسه از نو**: Shift + R  
- **پرش به اسلاید ۱ تا ۱۰**: اعداد ۱ تا ۹ و ۰  
- **پرش به اسلایدهای ۱۱ به بعد**: Shift + عدد  
- **اولین / آخرین اسلاید**: Home و End  

**در پرسش‌های داور:** پرسش بعدی `N`، نمایش پاسخ `Enter`، چینش تازه `R`.

میان‌برهای تک‌کلیدی را می‌توان از «تنظیمات خواندن» خاموش کرد؛ ترکیب‌های Alt و کلیدهای جهت‌دار همیشه فعال می‌مانند.

## قواعد نگارشی

- هیچ رقم یا حرف فارسی داخل عبارت‌های LaTeX نوشته نمی‌شود  
- زمان‌ها با ارقام فارسی و واژه «تا» نوشته می‌شوند؛ هیچ em dash یا en dash در محتوا به‌کار نمی‌رود  
- مدت اسلاید در فایل اسلاید با ثانیه (`durationSec`) و برچسب انگلیسی (`estimatedTime`) می‌آید  
- ظرف‌های فرمول چپ‌به‌راست و ایزوله هستند
